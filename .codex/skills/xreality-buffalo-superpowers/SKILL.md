# Xreality Buffalo Superpowers

## Direct the job

1. State assumptions, missing evidence, target runtime and success criteria.
2. Read only the phase reference needed below.
3. Seal inputs and revisions before an expensive or nondeterministic stage.
4. Run at most one heavy Metal stage; checkpoint, unload, clear cache and verify
   memory release before continuing.
5. Let deterministic gates reject. Never convert `not_measured` or `attention`
   into `pass`, and require named human review for master promotion.
6. Preserve the accepted master; create and gate all delivery variants as
   reversible candidates.
7. Retry only the failed stage. Prefer better real evidence over more seeds.

## Load the phase superpower

- Intake, uncertainty, category or routing: read
  [evidence-and-routing.md](references/evidence-and-routing.md).
- Shape, topology, parts, Blender, UV or LOD: read
  [geometry-and-blender.md](references/geometry-and-blender.md).
- Paint, texture, PBR or material regions: read
  [materials-and-pbr.md](references/materials-and-pbr.md).
- Packaging, web/XR/game delivery, benchmarking or optional cloud: read
  [delivery-and-cloud.md](references/delivery-and-cloud.md).

Do not load unrelated references “just in case”. Treat completion of a phase as
a context and resource boundary: persist the compact result, release models,
temporary renders and scenes, then proceed.

## Enforce the promotion equation

`input ∧ geometry ∧ parts ∧ topology ∧ UV ∧ texture ∧ material ∧ memory ∧ packaging ∧ target_runtime`

For `master`, additionally require sufficient real evidence, canonical renders
and named human review. Report the failed lane, evidence, threshold and safest
next action; never hide it inside a weighted score.

## Guard web escalation

Keep network off by default. Before Meshy, Rodin, Tripo or another provider:

1. show why local repair cannot meet the contract;
2. estimate maximum cost and data leaving the device;
3. obtain explicit opt-in;
4. pin provider/model/options and disable auto-refill;
5. import the output as untrusted and run the same local gates;
6. reconcile estimated versus actual credits and retain provenance.
