## Política mínima de entrada

Para ojos, manos, ruedas, interior de vidrio, mecanismos, cables, articulaciones o partes traseras: exigir una toma frontal nítida y las vistas reales necesarias. Si una parte crítica no se observa, el reporte debe decir `not_measured`; nunca `pass`.
